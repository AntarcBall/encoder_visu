# PRD — Autoencoder Interactive Site

## Product
Autoencoder Playground

## Goal
Turn `autoencoder.pdf` into an interactive, easy-to-understand, Vite-based educational website that explains core autoencoder concepts through guided sections and playful labs.

## Users
- ML beginners who need intuition before equations
- Students reviewing Deep Learning Book Chapter 14
- Readers who prefer interactive explanations over static summaries

## Requirements
1. 15+ sections/pages
2. Easy Korean explanations
3. Core topics covered: undercomplete, regularized, sparse, denoising, score estimation, manifolds, contractive autoencoders, PSD, applications
4. Interactive learning modules
5. Source trace / scope note / reference basis
6. Navigation + progress + recap/quiz
7. Game-like motivation via mission board and challenge lab

## Non-goals
- Full paper reproduction
- Real trained-model inference demo
- Full academic citation system

## Acceptance Criteria
- `npm run build` passes
- Syntax checks pass
- 15+ sections exist
- Challenge/game layer exists
- Source basis is visible
- Architect verification passes
